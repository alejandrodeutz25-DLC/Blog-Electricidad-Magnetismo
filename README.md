# Blog de Electricidad y Magnetismo
Blog web desarrollado con Django que publica apuntes y resumenes sobre Electricidad y Magnetismo: 
- Electro estatica
- Campo electrico
- Medios materiales
- Circuitos en corriente continua magnetoestatica en vacio
- Circuitos de corriente alterna

## Tecnologias
- Python
- Django

## Autor
Alejandro Deutz

## Fuente del contenido 
Los apuntes están basados en el curso "Electricidad y Magnetismo" de Gerardo Pozzi.
